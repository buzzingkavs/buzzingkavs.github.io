# Portfolio site

Deployed with GitHub Pages.

- `index.html` — the whole site (HTML + CSS in one file)
- `images/` — put your artwork here, named to match the `src=` lines in index.html

## To update
Edit index.html, commit, push. GitHub Pages rebuilds in ~1 minute.

## Images
Export at ~1600px wide, save as JPEG (quality 80) or WebP.
Keep each file under ~400 KB or the page will feel slow.
